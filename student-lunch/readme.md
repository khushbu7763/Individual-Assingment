
# Student Food Finder Finland

## About the Project

I created this website to help students find restaurants
and check their daily and weekly lunch menus in Finland.

Users can search for restaurants, filter them by city
or company, save their favorites and view restaurant
locations on a map.

## Features

- Search restaurants
- Filter by city and company
- View daily and weekly menus
- Save favorite restaurants
- View restaurant locations on a map
- Register, login and logout
- Mobile-friendly design

## Technologies Used

- HTML
- CSS
- JavaScript
- REST API
- LocalStorage
- Google Maps iframe

## How to Run

1. Download or clone this project.
2. Open the folder in VS Code.
3. Open index.html using Live Server.

## Resources

- Restaurant API: https://media2.edu.metropolia.fi/restaurant
- Food images: Unsplash
- Map: Google Maps

## What I Learned

During this project, I learned how to fetch data from
an API, display it on a website, use JavaScript for
search and filters, and create a responsive website.
